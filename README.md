# Node.js QR Code Generator

A command-line utility that takes a URL input from the user, generates a custom QR code image, and saves the text link into a file. Built as part of **Angela Yu's Complete Web Development Bootcamp**.

## 🛠️ Technologies Used
* **Node.js** - Runtime environment
* **Inquirer.js** - To handle interactive command-line user prompts
* **qr-image** - To generate the QR code image vector

## 🚀 How to Run Locally

1. Clone this repository to your local machine.
2. Install the necessary dependencies:
   ```bash
   npm install
   ```
3. Run the application:
   ```bash
   node index.js
   ```
